# goit-markup-hw-06

WebStudio — adaptive landing page based on the [Figma layout](https://www.figma.com/design/IfSLetpKFiApD2uqgGK2KA/Web-Studio--Version-5.1---Copy-?node-id=297046-1554).

## Features

- Mobile-first layout with breakpoints at **320px**, **768px**, and **1158px**
- Mobile menu toggled with the `.is-open` class
- Modal window for ordering a service
- Responsive hero background with `min-resolution` support
